📖 How to Export your Data (Instructions)
  1. Keep "Include Song Audio Files" checked if you want your actual song files backed up so you can transfer them to another device.
  2. Uncheck it if you only want to save your playlist names, markers, lyrics, and settings as a tiny lightweight file.
  3. Click "💾 Start Export" to save the .json file completely offline.
📖 How to Import & Restore your Data (Instructions)
  1. Click "📥 Select Backup File (.json)".
  2. Select the backup file previously downloaded from Amarjeet Audio Studio.
  3. The app will automatically restore all playlists, markers, hearts, lyrics, and media directly into local IndexedDB storage.
